# <i>DecisionAct</i> <br>
**Every Action Is a Decision**<br>Decision-Model-Driven Execution for Structured Agent Workflows


## Installation

Using pip:

```bash
pip install decisionact
```

Using uv inside a project:

```bash
uv add decisionact
```
