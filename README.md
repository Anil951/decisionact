# <i>DecisionAct</i> <a href="https://pepy.tech/projects/decisionact"><img align="right" src="https://static.pepy.tech/personalized-badge/decisionact?period=total&units=NONE&left_color=BLACK&right_color=BLUE&left_text=downloads" alt="PyPI Downloads"></a>

**Every Action Is a Decision**<br>Decision-Model-Driven Execution for Structured Agent Workflows

DecisionAct is a Python agent framework for building task-focused agents with
predefined intents, tools, and outcomes (with reply templates). Decision models
interpret user requests and select actions; your Python functions execute them.

## Installation

Using pip:

```bash
pip install decisionact
```

Using uv inside a project:

```bash
uv add decisionact
```

## Versions

Current source and documentation: **v0.1.2**. Earlier releases: **v0.1.1** and **v0.1.0**.

See the [changelog](https://anil951.github.io/decisionact/changelog)

[upgrade notes](https://anil951.github.io/decisionact/changelog#upgrading-from-v011).
